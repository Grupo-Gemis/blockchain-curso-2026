# Unidad 05 · Una interfaz que dice éxito demasiado pronto

La interfaz muestra Operación exitosa apenas obtiene un hash. Después la transacción revierte por permisos. El equipo debe corregir el flujo y proponer pruebas.

1. Explicar proveedor, firmante y configuración necesaria.
2. Corregir el momento en el que se muestra éxito.
3. Diseñar pruebas para cuenta no autorizada y desconexión.

# Aplicación guiada de certificados

Abrí [EMPEZAR-AQUI.md](EMPEZAR-AQUI.md) y seguí sus pasos. La carpeta contiene un contrato y una interfaz completos, dos documentos ficticios y las comprobaciones del caso.

La copia ejecutable se prepara desde la carpeta `laboratorio` del repositorio con `npm run preparar:certificados`. El comando muestra la carpeta de destino y conserva cualquier copia anterior. Esta fuente de ejemplo se mantiene sin dependencias, artifacts ni resultados locales.
